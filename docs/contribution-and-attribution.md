# Contribution and Attribution

## Project Context
This repository documents a collaborative academic project completed by Team Gravis, simulating a Managed Service Provider (MSP) supporting two anonymized client environments across two network sites.

## Team Scope
The following areas were designed and implemented collaboratively by the team:
- Overall network topology and routing architecture
- Firewall policy
- VPN / site-to-site connectivity (WireGuard)
- Active Directory and directory services
- Storage and backup (TrueNAS)
- Linux services and DMZ-hosted applications
- Final technical documentation and reporting

## My Individual Contributions
- Deployed VyOS router virtual machines in the Proxmox environment
- Configured and validated DHCP relay across routed network segments
- Worked on Windows Server infrastructure services, including DHCP, DNS, and DFS
- Participated in multi-site service testing, troubleshooting, and documentation

## Notes on Publication
- Client names have been anonymized (Client A / Client B) for public publication.
- Diagrams and screenshots will only be added once permission has been obtained from all team members and, where applicable, the course instructor.
- Configuration snippets included in this repository, if any, are sanitized and do not contain credentials, keys, or identifying information.
